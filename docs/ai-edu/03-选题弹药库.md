## 赛道 B：神经科学 × 心理学解毒

### B1. 八大高传播误区（核心弹药库）

| 流行说法 | 科学真相 | 证据强度 | 内容角度 | 优先级 |
|---------|---------|---------|---------|--------|
| 多巴胺 = 快乐分子 | 多巴胺是奖励**预期**/动机信号，不是快乐本身（Schultz 1997：预期时放电最强，获得后反而下降） | ⭐⭐⭐⭐⭐ | 刷短视频停不下来不是快乐，是预期成瘾 → "预期管理"替代"戒多巴胺" | ⭐ |
| 你只开发了大脑 10% | 全脑都在工作，静息态也有高能耗；不同任务激活不同网络 | ⭐⭐⭐⭐⭐ | 追踪谣言百年传播史（可能源于 William James 误引），用神经影像学反证 | ⭐ |
| 潜意识控制 95% 行为 | 无意识处理存在（自动化技能、内隐记忆），但"95%"无出处；意识与无意识是动态交互 | ⭐⭐⭐ | 弗洛伊德"潜意识" vs 现代认知神经科学"无意识处理" | ⭐ |
| 左脑理性，右脑感性 | 复杂认知双侧参与；语言偏左，但情绪调节、直觉需全脑整合 | ⭐⭐⭐⭐ | "裂脑人"实验的真正结论是什么 | |
| 杏仁核 = 恐惧中枢 | 杏仁核参与恐惧**学习**，但恐惧体验涉及脑岛、前额叶、下丘脑；也参与正性情绪 | ⭐⭐⭐⭐ | 为什么"克服恐惧"不能靠"理性说服杏仁核" | |
| 21 天养成习惯 | 神经可塑性存在但受遗传/年龄/环境约束；不是无限潜能 | ⭐⭐⭐⭐ | 习惯重塑神经回路的真实时间尺度和机制 | |
| 心流 = 大脑高度专注 | 心流时前额叶活动**降低**（transient hypofrontality），是自我意识的暂时消退 | ⭐⭐⭐⭐ | 为什么"逼自己专注"反而进不了心流 | |
| 镜像神经元让你理解他人 | 镜像神经元存在，但"理解他人"依赖心智化网络（TPJ、mPFC）；镜像理论被过度推广 | ⭐⭐⭐ | 从"镜像神经元"到"共情"之间跳过了多少步 | |

## 赛道 C：技术概念"第二层教材"（信任背书向，Phase 3+）

按"5 岁版 → 工程师版 → 研究者版"三层结构执行，每个概念 7 天 MVP。

| 概念 | 5 岁版钩子 | 为什么现在急需 |
|------|-----------|--------------|
| Agent（⭐ 已在对话中完整示范） | "AI 是坐着说话的专家，Agent 是站起来办事的项目经理" | 数百万人用 ChatGPT，理解模型与 Agent 区别的不到 1% |
| RAG | "让 AI 先查资料再回答，而不是全凭记忆" | 从朴素检索到多跳推理，含义变化剧烈，混用严重 |
| Transformer / 注意力 | "让 AI 在读一句话时，知道该盯着哪些词看" | 一切现代 AI 的地基，但"为什么需要注意力"极少有人讲 |
| Prompt Engineering | "不是写咒语，是设计交互协议" | 从"写提示词"到"设计交互"的范式迁移 |
| RLHF | "用人的偏好当尺子，教 AI 什么叫'好回答'" | 概念考古价值高：为什么 ChatGPT 比 GPT-3"懂事" |

### 术语考古地图（概念考古形态）

对同一术语按年代整理：时间 / 来源 / 当时定义 / 典型场景 / 与现在的区别。Agent 的示范表格已在源对话中给出（1990s Russell & Norvig → 2010s 强化学习 → 2023+ LLM + 工具调用），可直接复制此方法到 RAG、Prompt Engineering、Alignment 等术语。

## 选题评估 Checklist（新选题入库前过一遍）

- [ ] **痛点真实**：能在小红书/即刻/脉脉搜到真实吐槽，而不是自己想象的
- [ ] **反常识**：有一个"原来如此"的瞬间（多巴胺不是快乐 / 心流是降激活）
- [ ] **可视觉化**：能做 Before/After 对比或证据链展示
- [ ] **可执行**：读者看完知道下一步做什么
- [ ] **人设一致**：是"战友分享"口吻，不是"老师讲课"口吻
