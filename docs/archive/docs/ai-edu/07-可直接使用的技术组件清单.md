# 可直接使用的技术组件清单（附可借鉴范式）

> 来源：`06-交互式教学内容呈现方案调研.md` 中各方案的组件级拆解。
> 分两类：**A. 直接可用**（装上就能跑）与 **B. 可借鉴范式**（抄交互设计，不抄代码）。

---

## A. 直接可用的组件

### A1. 布局骨架类（解决"左右栏/上下/抽屉"）

| 组件 | 是什么 | 直接解决 | 安装 |
|------|--------|---------|------|
| **react-resizable-panels** | 三件套：`PanelGroup` / `Panel` / `PanelResizeHandle`。水平/垂直分栏、嵌套（IDE 三栏约 40 行）、`collapsible` 折叠、`autoSaveId` 布局记忆到 localStorage、键盘无障碍，约 12KB gzip | D1 多面板 + D2 唤出收起 | `npm i react-resizable-panels` |
| **shadcn/ui `Sheet`** | 上/下/左/右四向抽屉，Radix 底层 | 右侧"提示词库抽屉" | `npx shadcn add sheet` |
| **shadcn/ui `Resizable`** | 官方就是对 react-resizable-panels 的封装，与 shadcn 主题统一 | 分栏与整体风格一致 | `npx shadcn add resizable` |
| **shadcn/ui `Command`** | ⌘K 命令面板（搜索+唤出任意内容） | **"随意调用"的最成熟交互** | `npx shadcn add command` |
| shadcn/ui `Accordion` / `Tabs` / `ScrollArea` | 折叠区、页签、局部滚动 | L2 展开层、案例图集 | `npx shadcn add …` |

> 工作区已有 `webapp-building` skill（React + Tailwind + shadcn/ui 技术栈），以上全部在开箱范围内。

### A2. 文档/内容层类（Markdown 里直接用）

| 组件 | 来源 | 亮点 | 使用方式 |
|------|------|------|---------|
| **Fumadocs `Tabs`** | Fumadocs | `groupId` 跨页面联动选择、`persist` 存 localStorage（用户选过"在线文档"，全站 tab 都记住） | 可单独 `npx @fumadocs/cli add tabs` 装进任意 React 项目 |
| **Fumadocs `Accordion`** | 同上 | 支持 `id` + URL hash 直达展开（"分享链接直接定位到某个折叠答案"） | 同上 |
| **Fumadocs `Steps` / `Callout` / `Cards`** | 同上 | 步骤编号样式、提示块、卡片导航 | 同上 |
| **Mermaid** | 已在 WorkBuddyGuide 依赖里 | 流程图/决策树即代码，Skill 决策树可直接生成 | 仓库已有 |

### A3. 教学过程类（解决"步骤推进"）

| 组件 | 来源 | 可直接用的部分 |
|------|------|---------------|
| **Slidev `v-click` / `v-after` / `v-clicks`** | Slidev | 点击步进动画：一次只出现一个要点——"教学节奏"的现成实现 |
| **Slidev 代码行高亮动画** | Slidev | 代码块 `{none\|1\|2}` 语法：逐行高亮提示词的每一句 |
| **Slidev two-cols / iframe 布局** | Slidev | 左讲解右演示的内置页面布局 |
| **Slidev Presenter Mode** | Slidev | 演讲备注（L2 论述层）+ 录制 + 手机遥控 |
| **H5P 内容类型**（可 iframe 嵌入） | H5P | Image Hotspots（截图上 clickable 热点，正好讲解 WorkBuddy 界面）、Dialog Cards（术语翻转卡）、Interactive Video（视频内嵌题）——做好的 h5p 包可直接嵌入任何页面 |

### A4. 交互联动类（解决"内容块可操作"）

| 组件 | 来源 | 用法 |
|------|------|------|
| **Quarto `.panel-tabset` / sidebar / card / callout** | Quarto Dashboards | 声明式多面板页：Markdown 标题即布局，静态输出 |
| **Observable JS `Inputs`** | Quarto 内嵌 | 滑杆/复选框/下拉 → 全页内容联动重算（无需写 JS 框架代码） |
| **marimo `mo.sidebar` / `mo.hstack/vstack` / `mo.accordion` / `mo.ui.tabs`** | marimo | Python 侧的布局组件，实验性章节直接用 |
| **marimo 拖拽 Grid 编辑器** | marimo | 不懂布局代码也能拖出多面板应用 |

### A5. 编程教学类（仅代码章节）

| 组件 | 来源 | 用法 |
|------|------|------|
| **TutorialKit UI 包** | `@tutorialkit/react` 等 | 现成的编辑器/终端/文件树/预览窗格组件，Astro + React |
| **TutorialKit 内容结构** | TutorialKit | `content.md` + `_files/`（起始码）+ `_solution/`（答案）目录约定，直接照用 |

## B. 可借鉴的交互范式（抄设计）

| # | 范式 | 抄自 | 抄什么 | 用在教学驾驶舱哪 |
|---|------|------|--------|----------------|
| 1 | **⌘K 命令面板召唤一切** | Linear/VS Code（shadcn `Command` 可实现） | "随意调用"不用做 N 个按钮，一个搜索框召唤提示词/案例/章节/概念卡 | 全局，替代部分抽屉 |
| 2 | **IDE 三栏布局语言** | VS Code（react-resizable-panels 的嵌套示例即此） | 左导航 / 中主区 / 下面板 / 右inspector，全部可折叠可拖拽，布局记忆 | 整体骨架 |
| 3 | **Part > Chapter > Lesson 三级 + 起始/答案分离** | TutorialKit | 每课有"动手区"和"显示答案"按钮——把"跟练"结构化 | 章节内部结构 |
| 4 | **分支场景（Branching Scenario）** | H5P | 学习路径非线性：选 A 走这条路，选 B 走那条，不同结局不同反馈——"决策树教学" | 中央舞台的场景教学（如"这份表格该用哪个 Skill？"分支演练） |
| 5 | **声明式响应联动** | marimo / Observable | UI 控件值变化 → 引用它的内容自动更新，作者只声明依赖不写事件 | "调整参数看结果变化"类演示（如预算滑杆→行程方案变化） |
| 6 | **滚动驱动叙事（Scrollytelling）** | Idyll `Scroller`/`Stepper` | 滚动到某段，右侧图形切到对应状态——图文不再分离 | 特别篇深度文章 |
| 7 | **内容/解说双层** | Slidev speaker notes | 页面只放 L1 结论，论述放备注层——压缩策略的技术实现 | 所有 deck 页面 |
| 8 | **侧栏集中放输入控件** | Quarto Dashboards | 左边是"你调什么"，右边是"结果是什么"，职责分明 | 交互演示页布局惯例 |
| 9 | **逐行高亮讲解代码/提示词** | Slidev `{none\|1\|2}` | 一次只亮一行，配一句"这行是干什么的" | 提示词教学页 |
| 10 | **Image Hotspot 截图讲解** | H5P | 在软件截图上布热点，点哪讲哪 | 讲 WorkBuddy 主界面（第 3 章） |

## C. 映射到"教学驾驶舱"：每个需求用哪块积木

```
┌────────────────────────────────────────────────────┐
│ 顶栏：章节切换 + 进度 + ⌘K 命令面板 (A1 Command/B1) │
├──────────┬────────────────────────────┬────────────┤
│ 左栏      │ 中央教学舞台                │ 右抽屉      │
│ 章节树    │ L1 结论卡 + v-click 步进    │ 提示词库    │
│ (Panel,   │ (A3 Slidev 机制移植)       │ (A1 Sheet)  │
│  可折叠)  │ 分支演练 (B4)              │ 案例热点图  │
│          │ 提示词逐行高亮 (B9)         │ (A3 H5P式)  │
├──────────┴────────────────────────────┴────────────┤
│ 底部步骤条：痛点→框架→跟练→验收 (A2 Steps / B3)      │
└────────────────────────────────────────────────────┘
  全部分栏：react-resizable-panels（拖拽/折叠/记忆）(A1)
```

**最小可行组合**（第一版只装 4 个包）：
`react-resizable-panels` + shadcn `Sheet` + shadcn `Command` + MDX
——D1/D2 直接解决；D3 步骤条和 D4 交互组件随后迭代加入。
