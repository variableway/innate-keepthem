## 一句话战略

> 不做"教 AI 的人"，做"在 AI 时代帮人建立判断力的人"——
> 赛道 A（职场人 AI 提效）负责现金流和广度，赛道 B（神经科学×心理学解毒）负责深度和壁垒，共享同一个人设：**战友，不是老师**。

## Phase 速览

- **Phase 1（Week 1-4）冷启动**：双线各跑 30 天方案，验证有没有人愿意看 → 出 3 条有数据的内容 + 1 个小产品
- **Phase 2（Month 2-3）产品化**：从技巧到方法论系统，赛道 A 建 SOP，赛道 B 从解毒转建构
- **Phase 3（Month 4-6）规模化**：从"教工具"到"教怎么学"，建立增长飞轮（诊断→案例→内容→转化）
- **Phase 4（Month 7+）杠杆化**：从个人时间变现到产品体系变现，可与 innate 生态（ContentForge、Obsidian 模板、提示词库）结合

## 三条军规（所有内容必须遵守）

1. 展示"你也在用"，不做"我来教你"
2. 诚实标注不确定性，证据强度分级
3. 每条内容必须有可执行的下一步
