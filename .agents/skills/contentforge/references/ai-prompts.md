# AI 提示模板参考

## 摘要生成

### Structured 风格（默认）

```
请对以下内容生成结构化摘要：

内容：
{content}

要求：
1. 用 2-4 句话总结核心内容
2. 列出 3-10 个关键要点（带时间戳引用）
3. 识别目标受众
4. 提出 1-3 个行动建议

输出格式：
## Summary
[2-4 句总结]

## Key Points
- [时间戳] 要点 1
- [时间戳] 要点 2
...

## Audience
[目标受众描述]

## Action Items
1. [行动建议 1]
2. [行动建议 2]
```

### Concise 风格

```
用 100 字以内总结以下内容的核心观点：

{content}
```

### Bullets 风格

```
将以下内容转化为 bullet points（最多 10 条）：

{content}

每条要点不超过 20 字。
```

## 小红书文案转换

### 默认模板

```
请将以下内容转换为小红书风格的文案：

原始内容：
{content}

要求：
1. 语气亲切自然，像朋友分享
2. 适当使用 emoji 增加活力
3. 添加 3-5 个相关标签（#标签）
4. 字数控制在 500-1000 字
5. 开头要有吸引力（hook）
6. 结尾要有互动引导（CTA）
7. 使用小红书常用的表达方式

输出格式：
[标题]

[正文，含 emoji]

[标签]

[互动引导]
```

### 专业风格

```
请将以下内容转换为小红书专业风格文案：

原始内容：
{content}

要求：
1. 语气专业但易懂
2. 使用专业术语但附带解释
3. 适当使用 emoji 但不要过多
4. 添加 3-5 个精准标签
5. 字数控制在 800-1500 字
6. 结构清晰，使用小标题
7. 结尾提供价值总结
```

## 翻译

### 通用翻译

```
请将以下内容翻译成{target_language}：

{content}

要求：
1. 保持原文的语气和风格
2. 专业术语准确
3. 自然流畅，符合目标语言习惯
4. 保留原始格式（段落、列表等）
```

### 技术内容翻译

```
请将以下技术内容翻译成{target_language}：

{content}

要求：
1. 技术术语保持准确
2. 代码片段不翻译
3. 保留英文专业术语（首次出现时附翻译）
4. 保持技术文档的清晰结构
```

## 内容分析

### 深度分析

```
请对以下内容进行深度分析：

{content}

分析维度：
1. 主题识别：核心主题是什么？
2. 关键词提取：最重要的 5-10 个关键词
3. 情感分析：整体情感倾向（正面/中性/负面）
4. 目标受众：内容面向谁？
5. 内容质量：信息密度、原创性、可信度
6. 结构分析：内容组织方式
7. 亮点：最有价值的部分
8. 不足：可以改进的地方

输出格式：
## 主题
...

## 关键词
...

## 情感分析
...

## 目标受众
...

## 内容质量评分
...

## 结构分析
...

## 亮点
...

## 改进建议
...
```

### 快速分析

```
快速分析以下内容（每项不超过 2 句话）：

{content}

1. 核心观点：
2. 目标受众：
3. 情感倾向：
4. 关键信息：
```

## 风格改写

### 口语化 → 书面化

```
请将以下口语化内容改写为正式书面语：

{content}

要求：
1. 使用正式词汇
2. 句子结构完整
3. 避免口语表达和缩写
4. 保持专业语气
```

### 学术 → 通俗

```
请将以下学术内容改写为通俗易懂的科普文章：

{content}

要求：
1. 用比喻和类比解释复杂概念
2. 避免专业术语（必要时解释）
3. 增加趣味性和可读性
4. 适合普通读者阅读
```

## 提示模板变量

| 变量 | 说明 | 示例 |
|------|------|------|
| `{content}` | 原始内容文本 | 推文内容、文章正文 |
| `{summary}` | 已生成的摘要 | 用于小红书转换的输入 |
| `{target_language}` | 目标语言 | zh, en, ja, ko |
| `{style}` | 改写风格 | professional, casual, humorous |
| `{tone}` | 语气 | friendly, formal, enthusiastic |
| `{max_length}` | 最大字数 | 500, 1000 |
| `{emoji_density}` | emoji 密度 | none, low, medium, high |
